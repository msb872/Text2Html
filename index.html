راهنمای استفاده از Text2Html

در این برنامه می‌توانید فایل‌های متنی با فرمت‌های txt, bat, css و js را اضافه کنید، آن‌ها را دسته‌بندی نمایید و محتوای آن‌ها را مشاهده و ویرایش کنید.

  • برای افزودن فایل‌ها از طریق درگ و دراپ یا دکمه انتخاب فایل استفاده کنید.
  • می‌توانید فایل جدید به صورت دستی با وارد کردن نام، دسته‌بندی و محتوا اضافه کنید.
  • از دکمه‌های بالای صفحه برای خروجی گرفتن، ذخیره فایل‌ها و جستجو استفاده نمایید.
  • نام دسته‌بندی و فایل‌ها قابل ویرایش هستند.
  • برای باز و بسته کردن دسته‌بندی‌ها از دکمه «باز/بسته کردن همه دسته‌ها» استفاده کنید.
