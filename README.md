# Text2Html

تبدیل و مدیریت فایل‌های متنی به صورت تعاملی و خروجی HTML

---

## معرفی

Text2Html یک ابزار تحت وب ساده و کاربردی است که به شما امکان می‌دهد فایل‌های متنی خود را به راحتی مدیریت، دسته‌بندی، ویرایش و به فرمت HTML تعاملی تبدیل کنید. این پروژه به زبان فارسی و راست‌چین طراحی شده و مناسب کسانی است که می‌خواهند بدون نیاز به نرم‌افزارهای پیچیده، فایل‌های متنی خود را سازمان‌دهی و نمایش دهند.

---

## امکانات اصلی

- افزودن فایل‌های متنی به صورت کشیدن و رها کردن یا انتخاب از سیستم
- دسته‌بندی فایل‌ها و مدیریت نام دسته‌ها
- ویرایش نام و محتوای فایل‌ها در محیط وب
- جستجو در محتوای تمام فایل‌ها به صورت خط به خط با نمایش نتایج و هایلایت
- خروجی گرفتن از کل فایل‌ها به صورت:
  - فایل HTML تعاملی با قابلیت باز و بسته کردن دسته‌ها و فایل‌ها
  - فایل JSON برای پشتیبان‌گیری و بازیابی
  - فایل ZIP شامل تمام فایل‌ها در پوشه‌های دسته‌بندی شده
- قابلیت پرینت و کپی محتوا برای هر فایل و دسته
- ذخیره‌سازی خودکار داده‌ها در مرورگر (localStorage)
- حالت تاریک برای راحتی کار در محیط‌های کم‌نور
- راهنمای کامل استفاده و میانبرهای کیبورد

---

## نحوه استفاده

1. فایل `index.html` را در مرورگر خود باز کنید.
2. فایل‌های متنی خود را با کشیدن و رها کردن یا دکمه انتخاب فایل اضافه کنید.
3. می‌توانید نام دسته‌بندی را وارد یا انتخاب کنید.
4. فایل‌ها در دسته‌های مربوطه نمایش داده شده و قابل ویرایش هستند.
5. برای خروجی گرفتن از دکمه‌های بالای صفحه استفاده کنید.
